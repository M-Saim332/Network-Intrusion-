## 2. Baseline Model — Logistic Regression

### Objective

Establish a baseline performance using Logistic Regression for binary network intrusion detection on the UNSW-NB15 dataset.

The model classifies network records into two classes:

- `0` — Normal
- `1` — Attack

### Preprocessing

A Scikit-learn Pipeline was used to ensure consistent preprocessing during cross-validation.

- **Numerical features:** Median imputation and StandardScaler.
- **Categorical features:** Most-frequent imputation and OneHotEncoder.
- **ColumnTransformer:** Applies the appropriate transformations to each feature group.

### Validation Strategy

- Stratified 5-Fold Cross-Validation
- Out-of-fold predictions for evaluation
- Official testing dataset reserved for final evaluation.

### Evaluation Results

| Metric | Result |
|---|---:|
| ROC-AUC | 0.9842 |
| Precision | 92.92% |
| Recall | 98.07% |
| F1-Score | 95.43% |
| False Positive Rate | 15.93% |
| False Negative Rate | 1.93% |

*Precision, Recall, F1-Score, FPR and FNR above are calculated using the provisional decision threshold of 0.57.*

### Threshold Selection

The default classification threshold of 0.50 was investigated alongside alternative thresholds.

A threshold selection criterion was defined:

1. Maintain Recall of at least 98%.
2. Minimize False Positive Rate among thresholds satisfying this requirement.

The selected provisional threshold was **0.57**.

| Metric | Threshold 0.57 |
|---|---:|
| Precision | 92.92% |
| Recall | 98.07% |
| F1-Score | 95.43% |
| FPR | 15.93% |
| FNR | 1.93% |

### Initial Observations

- Logistic Regression demonstrates strong class-separation ability based on its ROC-AUC.
- The model achieves high attack detection recall.
- False positives remain an area for improvement.
- Threshold selection involves balancing attack detection against false alarms.

### Limitations and Next Steps

The threshold and metrics are based on out-of-fold predictions from the training dataset. Threshold selection on these predictions can introduce selection optimism.

The next steps are:

- Compare Logistic Regression with Decision Tree and Random Forest.
- Evaluate model generalization using the untouched official testing dataset.
- Perform final threshold validation and model evaluation.
- Investigate further improvements in false-positive reduction.
